# 02 — Issue Register & Severity Matrix

Status definitions used strictly across this register:
- **VERIFIED** — Reproduced or directly inspected, remediated, and verified via automated backend, unit, or real browser tests.
- **PARTIALLY VERIFIED** — Remediated in code and verified by unit/mocked tests, but full live-external-dependency verification (e.g., live TiDB/Docker/Render/Google JWKS/Gemini network) is pending deployment approval.
- **BLOCKED** — Cannot be executed in current local environment (e.g., live production DB/credentials).
- **NOT REPRODUCED** — Investigated and found already fixed or non-reproducible in baseline code.
- **DEFERRED** — Intentionally deferred to a follow-up architectural refactor (documented in `09_DEFERRED_REFACTORING_PLAN.md`).
